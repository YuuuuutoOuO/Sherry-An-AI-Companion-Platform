# Git Commit 命名規範

本專案對所有 Git Commit 名稱有嚴格的統一規範。**任何 AI Agent 與開發者在執行 `git commit` 時，必須 100% 遵守以下規則，嚴禁隨意使用未經規範的英文或簡寫**。

## 格式標準

```text
YY.MM.DD.NNN-簡明繁體中文描述
```

- **YY**：西元年末兩碼（例：`26`）
- **MM**：月份兩碼（例：`10`）
- **DD**：日期兩碼（例：`23`）
- **NNN**：當日三位數流水號，從 `001` 開始依序遞增（例：`001`, `002`, `003`）
- **-**：單一半形連字號
- **簡明繁體中文描述**：精確描述本次變更核心內容的繁體中文說明，避免模糊空洞字詞。

## 範例

- 正確範例：
  - `26.10.01.003-內容過濾放棄不再當作嚴重異常並修正稽核分類`
  - `26.10.22.001-模組化看板娘引擎支援多造型切換，移植橘雪莉桌寵版並提供自動轉換工具`
  - `26.10.23.001-WebUI提升PWA快取至v10、整合音樂韌性至Bot狀態並加入韌性中心自動重新整理`

- 錯誤範例（嚴格禁止）：
  - ❌ `fix(webui): bump PWA cache to v10`
  - ❌ `feat: add something`
  - ❌ `update code`
  - ❌ `26.10.01.004` (缺少描述文字)

## Commit 流程要求

1. 提交前，請先執行 `git log -1 --pretty=format:"%s"` 檢查今日是否已有 Commit，以決定當日最新流水號 `NNN`。
2. 確保使用上述格式作為 commit message 的第一行主旨。

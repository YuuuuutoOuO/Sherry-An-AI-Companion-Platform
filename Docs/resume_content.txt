H1:專案簡介
P:橘雪莉是一個擁有獨立人設（Soul）、會讀空氣、能自我反思的 Discord 虛擬群友與全能 AI 代理人（Agent）平台。系統整合 8 種 LLM 推理後端（Ollama / LM Studio / vLLM / OpenRouter / OpenAI / Gemini / DeepSeek / Claude），提供長期記憶、工具呼叫、語音互動、音樂播放、深度研究、數位繪圖與 Web 管理後台，並支援 Windows / Linux / Docker 部署。
P:專案自 2025 年起持續開發迭代至 v1.10.0，累積約 600+ 次 Git commit、約 11 萬行 Python 程式碼，並建置 CI（GitHub Actions）、pre-commit、mypy 與 Import-Linter 架構邊界檢查。

H1:核心技術亮點
H2:1. 分層解耦的微核心架構（Clean Architecture）
B:設計 App / Core / Handlers / Mod 四層架構：Orchestrator 抽離至應用層以消除循環依賴；Core 提供 Contracts、DB、Guard、Registry、State、Recovery 等基礎能力。
B:採用依賴倒置（IoC）與 Composition Root 注入客戶端，並以 Import-Linter 契約在 CI 強制檢查層間邊界，避免架構腐化。
B:10 個可插拔擴充模組（Mod）：深度研究、數位繪圖、實況劇院、股市虛擬交易、情報哨兵、D&D 跑團、小遊戲、YouTube 轉 GIF 等，與核心鬆耦合。
H2:2. LLM 推理效能最佳化（KV Cache / Prefix Caching）
B:提出 Zone 1（靜態：Soul 人設 + 精簡工具索引）/ Zone 2（動態：Vibe、歷史對話、記憶、世界觀）的 Prompt 分區策略，使 Pass-1（規劃）與 Pass-2（人格生成）的系統前綴 100% 位元組對齊。
B:Pass-2 可直接命中 Pass-1 建立的 5,500+ tokens 快取，免除二次 Prefill，TTFT 降至 < 200ms。
B:將工具 Prompt 精簡為 Compact Tool Index，每輪節省 900+ tokens；高頻查詢（記憶、股市）加入 Tier-1 TTL 快取，並以 asyncio.gather 並行調度工具。
IMG:【圖片位置 2】KV Cache 對齊流程圖 / 推理延遲（TTFT、cache_hit_ratio）前後對比截圖
H2:3. 系統自癒與重啟復原框架（Resilience & Recovery）
B:設計 core/recovery：以 SQLite WAL 持久化狀態快照（RecoveryStorage），開機時由 BootReconciler 進行冪等對帳，並加入 Crash-Loop 保護（短時間連續失敗 ≥ 2 次自動隔離，避免重啟迴圈）。
B:音樂播放斷點續播：重啟後自動重進語音頻道，並以 FFmpeg -ss 秒級接播、清理舊控制卡片。
B:AI 任務中斷復原：以 InFlightTaskRegistry 追蹤進行中的推理任務；短暫重啟（< 45s）自動重算並原地覆寫答案，超時則優雅更新訊息，消除殭屍 Loading 訊息；以 Semaphore 節流避免重啟後請求風暴。

H2:4. 長期記憶與 Agent 工具系統
B:長期記憶萃取、物理消毒與世界記憶；以相關度 + 重要性加權（rank = base_importance + relevance × 5.0）進行 Top-K 檢索，僅注入最相關記憶。
B:Two-Pass Agent：Pass-1 規劃並決定是否呼叫工具，Pass-2 以人格口吻整合結果；支援 Action Early Termination 以縮短回應時間。
B:LiveThinkingSession 即時展示思維鏈（message.edit）、SmartMessageDispatcher 處理 Discord 2000 字上限的智慧分段。
H2:5. 條件觸發推播（SPARK）與全景監控（APM）
B:SPARK 核心：支援價格監控、定期排程、RSS、天氣劇變 4 種觸發器，結合 NLP 自然語言意圖解析、智慧冷卻與防過度推播。
B:建立微觀延遲遙測（ttft_ms、prefill_latency_ms、decode_latency_ms、cache_hit_ratio）、健康哨兵與 /self-monitoring 稽核指令；ERROR 與系統警報自動私訊管理員。
